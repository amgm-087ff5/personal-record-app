## 1. 考え方

このアプリは**記憶を補う**ためのもの。だから設計の軸は3つ。

1. **時間が背骨** — 記録も予定も「時間の上に置かれたもの」。時刻を表す物差しを1つだけ持つ = **空の色**(夜の紺 → 朝焼け → 昼の青 → 夕焼け → 夜)。1日の帯(0〜24時)に、起きたこと(白い面)・これから(点線)・いま(赤い針)を置く。帯を見れば、どんな1日だったかが言葉なしで分かる。
2. **承認するだけ** — 入力は推し量って埋め、利用者は確かめて直すだけ。1行書けば種類(支払い・予定・ToDo・メモ)を推し量る。支払先から前回のカテゴリを引く。過ぎた予定は「記録にする」の1タップ。
3. **思い出せる** — 全部を横断してさがせる。1年前・1か月前・先週の同じ日を出す。人や場所のページが、その縁の記憶の入口になる。

### v7 の方針(見た目)
- **面・線・影を減らす**: 影のある白い面は「押すと開く独立した物」だけ。並び(rows/prop)・設定・入力のまとまり・統計(stats)・空の状態は白のフラット(影なし)で、区切りは左を空けた細い線だけ。まとまりは余白(セクション間 28px)で区切る。
- **文字の強弱**: 主役の数字(時刻・金額)は太く大きく、字間を詰め、等幅数字。ページの題は big の太字。
- **色を澄ませる**: 地 #F3F6FB、紺の文字、澄んだ青 #2563FF。くすみ・紫みを抜いた。
- **ワクワク**: 空の色を主役に(ホーム最上部)、触った時の手応え(動き)。
- **最低限のグラデと影**: グラデは「空(時刻)」と「青の塗り(主な操作・今日)」の2つの意味だけ。

## 4. 意味表(見た目 → 意味)。ここに無い見た目は作らない

### 4.1 色(1色 = 1意味)
| 色 | 意味 |
|---|---|
| 空のグラデ `--sky` | 時刻(0〜24時)。この意味だけ。帯・日の表示の縦の物差し・写真の枠 |
| 青 `--me` | 自分(自分の負担・今日・選択中・押せる操作) |
| 紺灰 `--done` | 起きたこと(記録) |
| 青緑 `--kin` | エンティティ(自分以外の人・場所・物) |
| 赤 `--over` | **ToDoの期限切れだけ**(2026-11-13 ユーザー指示「赤を使いすぎない」)。いま・過ぎた予定・休日・録音・エラー・見出しには使わない |
| 琥珀 `--owe` | 貸し借り・未精算(斜線もこの意味だけ) |
| 灰の点線 | まだ起きていない(予定)・足せる所(空の欄) |
| 青灰の点々 `--read` | 読み取った値(未確認)・自動で変換した値(未確定)。確かめる/確定すると消える |
| カテゴリの色 | 利用者のデータの色。小さい四角と棒の区間だけ |

### 4.1b v7 で足した意味
| 見た目 | 意味 |
|---|---|
| 影(`--e1/e2/e3`) | 浮いている物。押すと開く独立した物(記録・支払い・メモ・確かめる・思い出す・日の見出し)、ナビ(`--e-nav` 薄い影)、シート・トースト。並び・設定・入力・統計には付けない |

| ホームの空の面 | 「いま」の面は、いまの時刻の空の色の塗り(`skyFace(NOW)`)。中に大きい時刻と空の帯(帯の地は白い面 `--sky-track`)。文字色は輝度で紺/白に自動で切り替え、どの時刻でも 5:1 以上。意味 = 空の色 = 時刻(既存の延長) |

### 4.3 強さの順位
ホーム: いまの時刻と空の帯 > 次の予定 > 確かめる > 今日の支出 > ほか。アクティビティ: 今日の見出し(青の塗り)> いまの線 > 各日。詳細: 題 > 時刻 > 中身。家計簿: その月の自分の支出 > 棒 > 一覧。

### 4.4 言葉
説明文は置かない(形で示す)。用語: アクティビティ(記録の総称)/ 予定 / 支払い(事実)/ 支出(家計簿)/ エンティティ / メモ / ノート(エンティティごとの長い文)/ ToDo / **書く(＋の画面)/ 雑記(種類を選ばず置いた言葉)/ 未確定(自動で変換しただけの記録)/ 確定(未確定を実体にする。ボタンも「確定」)/ 置く(雑記に置く)**。ボタンとトーストの動詞を揃える。削除は「消す」、編集は「直す」。意図した例外: ホームの「固定費を除く」(大事な前提)。

### 4.5 値
全て `css/tokens.css`。文字は M PLUS 2(同梱。通信なしで表示できる)。文字の段階 48 / 30 / 20 / 15 / 13 / 12(12 未満は使わない)。押せる所は 44px 以上。余白は 4 の刻み。
段階の外は名前を付けたものだけ(見た目を保つため): 文字 `--fs-day`34 / `--fs-sub`17 / `--fs-lead`16 / `--fs-jumbo`64、余白 `--s-hair`2 / `--s-tight`3 / `--s-snug`6。色の成分 `--white-rgb` `--ink-rgb` は `rgb(var(--x-rgb) / 不透明度)` で使う(直書きの rgba・#fff は置かない。audit.py が検査)。＋の数は青(白地・青の縁)。赤は ToDo の期限切れだけ。

## 7. v6.3 入力 2(2026-11-12。詳細は INPUT2.md)
- 「入力」は全画面のモーダル。入力欄に焦点がある間は **記録モード**(種類の列・入力欄・「こう記録します」の札・道具の列・操作)、無い時は **履歴モード**
- 読み取りは **区切り**(改行・空白・読点・音声の間)で行う。独立した語だけを項目にし、読みに強い/弱いを付ける。弱い読み・読んだ語の小札は既存の `--read`(点線)で見せる。新しい色・形は無い
- 感想の文は記録にせず「日記に書く」を勧める。空行は記録の区切り

## 8. v6.4 入力 3(2026-11-13。詳細は INPUT3.md)
- 記録モードは上から ①記録予定のカード(残りの高さ)②種類 ③確定・下書き保存 ④入力欄(3行固定)⑤[日付の行][音声(中央・大)][改行 ¥ #]。焦点が外れても記録モードのまま。記録⇄履歴は見出し右のボタンだけ
- 読み取りは **行ごと**: 1行目(`#`の行を除く)=題で中は読まない。2行目以降がプロパティ(日付・時刻・金額・タグ・種類)。例 `/10 19:30` `+0 20:30`(同じ日)。音声は間(ま)=改行
- 履歴は、作った/直した/消したを横長のカード、未確定のカードは吹き出しの外。確定・直すのボタンはカードの下の外

## 構造の手がかり(線) — v7.2 追加(標準 3.13)
並びの性質を、左のごく淡い線(--rail・1.5px)で見せる。線があるだけで、ただの一覧が「時間の流れ」「階層」に読める。
- 時間の並び: 縦線 + 小さな点。済んだ所は実線、これからは破線。日のかたまりも線でつなぐ(ホームの今日の流れ .fl / 家計簿の日別 .lg-dg / メモの日別 .rl-day / 日のページ・アクティビティ・エンティティの移り変わり)
- 階層の並び: 親の目印の真下を通る縦線を段ごとに1本(種類の木 .en-tr / カテゴリの木 .lg-n.d1〜d3)
- 変化の履歴: 縦線 + 点(.rl-h。事実の履歴)
- 当てない: 順序に意味のない一覧(設定・選択肢)。新しい一覧は「時間か階層か履歴か」を先に決める
