# 個人記録 UI — 設計の核「時間と縁」

## このドメインは何か
記憶を補うための個人記録。記録の正体は **「いつ(時間)」に「誰・どこ・何(縁)」が交わった点**であり、お金はその点から流れ出る量。
データモデル: アクティビティ=時間上の点(日記=1日)。予定=まだ起きていない点。エンティティ=時間をまたいで続くもの(事実は版=期間を持ち、関係も期間を持つ)。支払い=点、自分の支出=その点の金額のうち自分の分。

## 1つの形: 時間軸
アプリ全体に1本の縦の時間軸が通る。**上が未来、下が過去。「いま」の線**が境目。
- 記録 = 塗りつぶした節(実線の軸)。予定 = 中抜きの節(点線の軸)。終わった予定は「記録にする」で実線に変わる。
- 日 = 軸の区切り(日付の見出し)。見出しを押すとその日のページ(日記)。
- どの画面も「時間軸をどう切り取ったか」で表す:
  - タイムライン = 全部の軸
  - 出来事の詳細 = その点の前後を切り取った軸
  - 人・場所の詳細 = **その縁の糸だけで切り取った軸**(会った点+事実が変わった点+関係が始まった点)
  - 家計簿の一覧 = お金の流れた点だけの軸
  - 予定 = 未来側の軸(点線)

## 縁(エンティティ)の形: 輪郭で種類を表す
フォルダではなく、**現実のものの輪郭**: 人物=円(顔) / 場所=地図のピン / 会社=角の四角(建物) / 物=六角 / 書類=角折れの紙。色は糸の色(人物=青、場所=ティール、会社=スレート、物=緑、書類=灰)。
出来事には、交わった縁の輪郭が「結び目」として並ぶ。一覧では各縁の**最近の出会い(12週の点)**を見せ、「最後に会ったのはいつか」を一目で分かるようにする(記憶の補助)。

## お金の形: 割合
支払いは合計の棒、自分の支出はその棒の中の**自分の分の区間**。立替は相手の区間(未精算は斜線)。家計簿の月は大分類の積み上げ。

## 視覚
IBM Plex Sans JP。背景 #F4F6F9 の冷たい紙、面は白、光は左上から(主役の上端ハイライト・柔らかい影)。ブランド青 #2D59B8。明朝・紫系・茶色・説明文の段落は使わない。軸がこのアプリで唯一の強い要素で、ほかは静かに。

## UX
作成の入口は中央の＋のみ(開いているタブで先頭が変わる)。1件1行。最小文字12px、タップ44px。取り消せる操作はトーストで取り消し。ダークモード・幅900以上は左レール。

## 表現の根拠(11/01 追加。根拠のない表現は使わない)
| 表現 | 意味(根拠) |
| --- | --- |
| 縦の時間軸・実線・塗りの節 | 記録 = 過去に起きた時間上の点 |
| 点線・中抜きの節 | 予定 = まだ起きていない点。記録になると塗りに変わる |
| 赤い「いま」の線 | 未来と過去の境目 |
| 円 / ピン / 建物 / 六角 / 紙(塗り) | 縁の種類の根(人物 / 場所 / 会社 / 物 / 書類)。現実の輪郭 |
| 塗りのカプセル(出来事の詳細) | 時間に掛かった1つの点。軸の節から横に掛ける |
| └ でぶら下がる白い面 | 親の子(支払い → 自分の支出) |
| 棒の中の区間 / 斜線 | 支払いのうち自分の分 / 立替・未精算の分 |
| 支払いの棒 → 拡大(自分の支出の詳細) | 自分の支出 = 支払いの中の自分の区間を取り出したもの |
| 1つの面に複数行 | 1つのオブジェクトの属性・部分(品目、関わった人、内訳) |
| 1件ずつ別の面 | 独立したオブジェクト(人・場所、ToDo、カテゴリ、種類) |
| タブ: 軸と節 | タイムライン = 時間軸そのもの |
| タブ: 点線と中抜きの節 | 予定 = 未来側の軸(画面内の予定の節と同じ記号) |
| タブ: 円とピン | 人・場所 = 縁の輪郭 |
| タブ: 棒の一部と括弧 | 家計簿 = 支払いのうち自分の区間を集めたもの(自分の支出の詳細の拡大と同じ図) |

## 画面の最上部(ページの正体)
- 出来事: 細い軸に掛かったカプセル(前後の出来事を日をまたいで表示)。時刻列はなし
- 予定: 点線の軸に掛かった中抜きのカプセル
- 自分の支出: 親の支払いの棒 → 自分の区間の拡大
- 日: 大きな日付と日記の本文
- 人・場所: 大きな輪郭と名前、種類のパンくず
