# 個人記録 UI — 設計の核「時間と縁」

## このドメインは何か
記憶を補うための個人記録。記録の正体は **「いつ(時間)」に「誰・どこ・何(縁)」が交わった点**であり、お金はその点から流れ出る量。
データモデル: アクティビティ=時間上の点(日記=1日)。予定=まだ起きていない点。エンティティ=時間をまたいで続くもの(事実は版=期間を持ち、関係も期間を持つ)。支払い=点、自分の支出=その点の金額のうち自分の分。

## 1つの形: 時間軸
アプリ全体に1本の縦の時間軸が通る。**上が未来、下が過去。「いま」の線**が境目。
- 記録 = 塗りつぶした節(実線の軸)。予定 = 中抜きの節(点線の軸)。終わった予定は「記録にする」で実線に変わる。
- 日 = 軸の区切り(日付の見出し)。見出しを押すとその日のページ(日記)。
- どの画面も「時間軸をどう切り取ったか」で表す:
  - タイムライン = 全部の軸
  - 出来事の詳細 = その点の前後を切り取った軸
  - 人・場所の詳細 = **その縁の糸だけで切り取った軸**(会った点+事実が変わった点+関係が始まった点)
  - 家計簿の一覧 = お金の流れた点だけの軸
  - 予定 = 未来側の軸(点線)

## 縁(エンティティ)の形: 輪郭で種類を表す
フォルダではなく、**現実のものの輪郭**: 人物=円(顔) / 場所=地図のピン / 会社=角の四角(建物) / 物=六角 / 書類=角折れの紙。色は糸の色(人物=青、場所=ティール、会社=スレート、物=緑、書類=灰)。
出来事には、交わった縁の輪郭が「結び目」として並ぶ。一覧では各縁の**最近の出会い(12週の点)**を見せ、「最後に会ったのはいつか」を一目で分かるようにする(記憶の補助)。

## お金の形: 割合
支払いは合計の棒、自分の支出はその棒の中の**自分の分の区間**。立替は相手の区間(未精算は斜線)。家計簿の月は大分類の積み上げ。

## 視覚
IBM Plex Sans JP。背景 #F4F6F9 の冷たい紙、面は白、光は左上から(主役の上端ハイライト・柔らかい影)。ブランド青 #2D59B8。明朝・紫系・茶色・説明文の段落は使わない。軸がこのアプリで唯一の強い要素で、ほかは静かに。
