# 個人記録 デザインシステム — 全要素の意味

規則: **ここに意味が書かれていない要素は使わない。** 1つの見た目は1つの意味だけを持つ。同じ意味は必ず同じ見た目にする。新しい要素を足すときは、先にこの表へ意味を書く。

---

## 0. ドメイン(すべての意味の出どころ)
- 記録は「いつ」に「誰・どこ・何(縁)」が交わった**点**。アプリ全体に1本の縦の**時間軸**が通る(上=未来、下=過去)。
- クラス: **出来事**(日記の子。支払い・会話・移動・出来事) / **予定**(まだ起きていない出来事) / **ToDo**(やること) / **縁**(人物・場所・会社・物・書類。時間をまたいで続く) / **メモ**(縁に綴じた文章) / **自分の支出**(支払いのうち自分の分) / **カテゴリ**(自分の支出の分類) / **種類**(縁の分類)。

---

## 1. 全体のレイアウト
| 要素 | 意味 |
| --- | --- |
| 下部ナビ(4つ+中央) | 同じ記録を見る4つの切り口。左から「時間の全体」「未来」「縁」「お金」。中央は作ること |
| 幅900以上: 左のレール | 同じ4つの切り口。画面が広いので常に横に置く |
| 幅900以上: 2列(一覧+詳細) | 一覧で選んだものを、一覧を残したまま右で開く(どこから来たかを失わない) |
| 中央の＋(浮いた丸角の正方形) | 「新しい点や縁を足す」唯一の入口。浮いている=どの画面の上でも使える |
| 画面の大見出し(28px) | タブの最上位=その切り口の全体を見ている。詳細画面には出さない |
| 上部バー(戻る＋右の操作) | 1つのものを開いている。戻る=来た場所へ。右=このものへの操作 |
| 下から出るシート | 今の画面の上に重ねた一時的な作業(作成・編集・選択)。閉じれば元の場所 |
| 下のトースト | 自分の操作の結果。取り消せる操作には「取り消す」 |

## 2. 画面の最上部(ページの正体)
最上部の形=そのページのクラス。クラスが違えば最上部の形も違う。
| ページ | 最上部の形 | 意味 |
| --- | --- | --- |
| タイムライン | 大見出し+時間軸の上端(未来へ消える点線) | 時間の全体の、いまの位置 |
| 予定タブ | 大見出し+月 | 未来を日付で見る |
| 人・場所タブ | 大見出し+検索 | 縁を名前で探す |
| 家計簿タブ | 大見出し+月とその月の自分の支出の棒 | お金を月で見る |
| 出来事の詳細 | 細い軸に掛かった**塗りのカプセル**+前後の点 | 時間上の1点(起きた) |
| 予定の詳細 | 点線の軸に掛かった**点線・中抜きのカプセル** | 時間上の1点(まだ起きていない) |
| 日のページ | 大きな日付と日記の本文 | 1日=1ページ |
| 自分の支出の詳細 | 親の支払いの**棒** → 自分の区間を**拡大した帯** | 支払いの一部を取り出したもの(時間上の点ではない) |
| 縁の詳細 | 大きな**輪郭**+名前+種類のパンくず | 時間をまたいで続くもの |
| メモ | 上に持ち主の縁、紙の本文 | 縁に綴じた文章 |
| ToDo の詳細 | 大きな**チェック欄**+題名 | やること |
| 種類・カテゴリ | 上部バー+木 | 分類の階層 |

## 3. 面(surface)
| 要素 | 意味 |
| --- | --- |
| 背景(冷たい灰白) | 記録が置かれる地面。何も載っていない所 |
| 影のある白い面(e1) | **1つの独立したオブジェクト**。押すと開く |
| 影の濃い面(e2) | このページの主役のオブジェクト |
| 浮いた面(e3) | 内容の上に浮く操作(＋、シート、トースト) |
| 影のない枠線の面 | **このページのオブジェクトの属性・部分**の集まり(品目、関わった縁、内訳)。中の行はオブジェクトではない |
| 面と面の間 8px | 別々のもの |
| 枠線の面の中の区切り線 | 同じものの別の属性 |
| 光(左上の白い反射) | 主役のオブジェクトが手に取れる実物であること。主役だけに使う |

## 4. 時間軸
| 要素 | 意味 |
| --- | --- |
| 縦の実線(灰) | 過去=起きた時間 |
| 縦の点線(灰) | 未来=まだ起きていない時間 |
| 赤い横線と「いま 13:20」 | 未来と過去の境目。点は付けない(点=出来事と混ざるため) |
| 軸を横切る短い太線+日付 | 日の区切り。押すとその日のページ |
| 軸を横切る短い太線+月 | 月の区切り(縁の時間軸) |
| 左の時刻列 | 一覧でのみ。点の時刻を揃えて読み比べるため。詳細では使わない(主役に幅を使う) |
| 上端で薄れて消える点線+「明日以降の予定」 | 未来の続きは予定タブにある |
| 下端で薄れて消える実線 | 過去の続き(読み込み) |
| 縁の時間軸の線の色=縁の色(青緑) | その縁だけを通る糸 |

## 5. 形(1つの形=1つの意味)
| 形 | 意味 |
| --- | --- |
| **カプセル**(横長の丸) 塗り | 起きた出来事(時間上の点)。軸上の小さい節も同じ形 |
| **カプセル** 点線・中抜き | まだ起きていない出来事=予定 |
| カプセル 点線・赤の枠 | 時間が過ぎたのに記録になっていない予定 |
| **円** | 人物 |
| **ピン** | 場所 |
| **建物**(上が段の縦長) | 会社 |
| **六角** | 物 |
| **角を折った紙** | 書類 |
| 縁の形 輪郭だけ(中抜き・実線) | 未登録の縁(名前だけある) |
| **ひし形**(縁の時間軸) | 縁の事実が変わった・関係が始まった時点 |
| **チェック欄**(角丸の正方形の枠) | ToDo。塗り=完了 |
| **短い横棒**(角丸の小さい帯) | カテゴリ(お金の棒の区間と同じ形=そのカテゴリの分) |
| **横の棒** | 1つの支払いの金額。区間に分かれる |
| 棒の区間 青の塗り | 自分の分 |
| 棒の区間 灰の塗り | ほかの人の分(精算済み・立替なし) |
| 棒の区間 **斜線**(琥珀) | 立替で未精算のお金。斜線はこの意味だけ |
| └ の線 | 親 → 子(支払い → 自分の支出)。この意味だけ |
| 縦の細いガイド線+字下げ | 分類の階層(種類・カテゴリの親子) |
| 台形の拡大(棒の区間→帯) | その区間を取り出して見ている |
| 丸い錠剤形(ピル) | **操作**(絞り込み・切替)。データには使わない |
| 角丸の小さい四角のラベル(タグ) | データに付いた分類の名前(カテゴリ・種類) |
| ✦ | 非日常(特別な支出)。色ではなく印で示す |

## 6. 色(1つの色=1つの意味)
| 色 | 意味 |
| --- | --- |
| 墨(#141B28〜) | 文字・確定した出来事の節・日の区切り |
| **青**(#2D59B8) | **自分**: 自分の分、自分の操作(主ボタン)、自分の輪郭、今日 |
| **青緑**(#13838A) | **縁**(自分以外): 人・場所などの輪郭、縁の糸 |
| **赤**(#D3393B) | **いま・時間に遅れている**: いまの線、期限切れ、過ぎた予定 |
| **琥珀**(#B86A0E) | **貸し借り**: 立替・未精算 |
| 灰(線・補助文字) | 未来の軸・補助情報・ほかの人の分 |
| カテゴリの色 | 利用者が決めたデータの色。カテゴリの帯と棒の区間だけに使う |
| 使わない色 | 紫(AIらしい配色)・茶色・強いグラデーション(過去の指示) |

## 7. 塗りと輪郭
| 表現 | 意味 |
| --- | --- |
| 塗り | 実在・確定(起きた出来事、登録済みの縁、自分の分、完了したToDo) |
| 点線の輪郭 | まだ起きていない(予定・未来の軸) |
| 実線の輪郭だけ | 未登録・未完了(未登録の縁、未完了のToDo) |

## 8. 角丸
| 半径 | 意味 |
| --- | --- |
| 完全な丸み(カプセル) | 出来事・予定 |
| 999(ピル) | 操作(チップ・切替・ナビの選択) |
| 14〜20 | オブジェクト・属性の面(主役は20) |
| 6〜8 | タグ(データに付いたラベル) |
| 18(＋) | 浮いた作成ボタン |

## 9. 文字
| 大きさ・太さ | 意味 |
| --- | --- |
| 36〜76 / 700 | 主役の量(金額・日付)。そのページで一番大事な値 |
| 28 / 700 | タブの大見出し |
| 20 / 700 | 主役の名前 |
| 17 / 600 | シートの題、主要な数値 |
| 15 / 500 | 行の題(オブジェクトの名前) |
| 15 / 400 | 本文 |
| 13 / 600 | セクション見出し=**このページのオブジェクトとの関係**(「交わった人・場所」「品目」) |
| 13 / 400 | 行の補足(場所・カテゴリなど) |
| 12 / 400 | 最小。日付の曜日・単位 |
| 等幅数字 | 金額・時刻を縦に揃えて比べる |
| 12px未満 | 使わない |
| セクション見出しの右の数 | その関係にあるものの件数 |
| セクション見出しの右の青い文字 | その関係への操作(「誰の分か表示」など) |

## 10. 余白
4の倍数。画面の左右16。面と面8(別のもの)。セクション間24(別の関係)。見出し→中身8。行の高さ最小52、押せる所は最小44。

## 11. アイコン(線2px・24の格子)
| アイコン | 意味 |
| --- | --- |
| タブ: 縦線と節 | タイムライン=時間軸そのもの |
| タブ: 点線の縦線と点線のカプセル | 予定=未来側の軸 |
| タブ: 円とピン | 人・場所=縁の輪郭 |
| タブ: 棒の一部と括弧 | 家計簿=支払いのうち自分の区間を集めたもの |
| ＋ | 作る |
| ‹ | 来た所へ戻る |
| … | このものへのほかの操作 |
| › | 押すとそれを開く |
| 「前の月」「次の月」「前の日」「次の日」(文字) | カレンダー・家計簿の期間の移動。‹ › は「戻る・開く」の意味なので使わない |
| ⌃ / ⌄(日のページ) | 次の日 / 前の日。時間軸と同じく上=未来・下=過去 |
| ✕ | シートを閉じる(作業をやめる) |
| 虫眼鏡 | 名前で探す |
| ペン | 書く・直す |
| カード | 支払い(出来事の種類)・支払い方法 |
| 吹き出し | 会話 |
| 斜めの矢印 | 移動 |
| 光の点 | そのほかの出来事 |
| 開いた本 | 日記 |
| ピン(小) | 場所(補足行) |
| カメラ / 写真 | レシートを撮る / 選ぶ |
| 棒の一部 | 自分の支出 |
| チェック | ToDo・完了 |
| ゴミ箱 | 削除(取り消せる) |
| 鐘 | 通知 |
| 輪の矢印 | 繰り返し |
| 線3本(文章) | メモ |
| ラベル(値札) | 種類 |
| 帯の束 | カテゴリ |

## 12. 動き
| 動き | 意味 |
| --- | --- |
| シートが下から上がる | 今の画面の上に一時的な作業を重ねた |
| トーストが下から出る | 操作の結果 |
| 画面の切替(短いフェード) | 別のものを開いた |
| それ以外の動き | 使わない |

## 13. 言葉
- 利用者の言葉で、能動で具体的に(「支払いを保存」)。ボタンとトーストの動詞を揃える(「記録にする」→「記録にしました」)。
- 説明の文章は書かない。形で伝える(過去の指示)。
- 同じものは同じ名前(出来事の題名を見出しに、店は補足行)。
