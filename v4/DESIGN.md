# 個人記録 デザインシステム — 全要素の意味

規則: **ここに意味が書かれていない要素は使わない。** 1つの見た目は1つの意味だけを持つ。同じ意味は必ず同じ見た目にする。新しい要素を足すときは、先にこの表へ意味を書く。

---

## 0. ドメイン(すべての意味の出どころ)
- 記録は「いつ」に「誰・どこ・何(縁)」が交わった**点**。アプリ全体に1本の縦の**時間軸**が通る(上=未来、下=過去)。
- クラス: **出来事**(日記の子。支払い・会話・移動・出来事) / **予定**(まだ起きていない出来事) / **ToDo**(やること) / **縁**(人物・場所・会社・物・書類。時間をまたいで続く) / **メモ**(縁に綴じた文章) / **自分の支出**(支払いのうち自分の分) / **カテゴリ**(自分の支出の分類) / **種類**(縁の分類)。

---

## 強さの階層(11/01 追加)
- 同じ意味は1か所で1回だけ言う(今日=青い線、いま=赤い線と赤い時刻、日の合計は支払いが2件以上の日だけ)。
- 強い印(塗り・太線・色)は1行に1つ。区切り線・時刻・補足は細く・灰で静かにする。
- 読めない文字(切れて「コ…」になる文字)は置かない。数だけ伝えたい所は印で示す。

## 1. 全体のレイアウト
| 要素 | 意味 |
| --- | --- |
| 下部ナビ(4つ+中央) | 同じ記録を見る4つの切り口。左から「時間の全体」(タイムライン)「未来」(予定)「縁」(人・場所)「お金」(家計簿)。中央は作ること |
| 幅900以上: 左のレール | 同じ4つの切り口。画面が広いので常に横に置く |
| 幅1100以上: 2列(一覧+詳細) | 一覧で選んだものを、一覧を残したまま右で開く(どこから来たかを失わない)。何も選んでいない時の右は空(説明文を置かない) |
| 一覧で右に開いているもの=薄い青の面 | 自分が選んだもの(青=自分の操作)。左の線は使わない |
| 詳細を開いても下部ナビのタブは変わらない | どこから来たかを失わない(タイムラインから自分の支出を開いてもタイムラインのまま) |
| 中央の＋(浮いた丸角の正方形) | 「新しい点や縁を足す」唯一の入口。浮いている=どの画面の上でも使える |
| 画面の大見出し(28px) | タブの最上位=その切り口の全体を見ている。詳細画面には出さない |
| 上部バー(戻る＋右の操作) | 1つのものを開いている。戻る=来た場所へ。右=このものへの操作 |
| 下から出るシート | 今の画面の上に重ねた一時的な作業(作成・編集・選択)。閉じれば元の場所 |
| 下のトースト(白い浮いた面) | 自分の操作の結果。取り消せる操作には「取り消す」(青=自分の操作) |

## 2. 画面の最上部(ページの正体)
最上部の形=そのページのクラス。クラスが違えば最上部の形も違う。
| ページ | 最上部の形 | 意味 |
| --- | --- | --- |
| タイムライン | 大見出し+時間軸の上端(未来へ消える点線) | 時間の全体の、いまの位置 |
| 予定タブ | 大見出し+月 | 未来を日付で見る。月のマスは件数の印だけ(小さいカプセル: 塗り=記録、点線=予定、最大4)。中身は下の日の一覧で読む |
| 人・場所タブ | 大見出し+検索 | 縁を名前で探す。各行の右に「最後に交わった日」と**12週の出会いの棒**(1本=1週、高さ=その週に交わった回数。記憶の補助) |
| 家計簿タブ | 大見出し+月とその月の自分の支出の棒 | お金を月で見る |
| 出来事の詳細 | 上に日のカード(親=その日。押すと日のページ)、上下で薄れて消える細い軸の切れ端に掛かった**塗りのカプセル** | 時間上の1点(起きた)。前後の出来事は出さない(軸の切れ端だけで「タイムラインの一部」を示す。v2と同じ)。カードの骨格は予定と同じ: 種類と時刻 / 題名 / 金額 / 場所・人 / 種類ごとの行(支払いの棒など) |
| 予定の詳細 | 上に日のカード、薄れて消える点線の軸の切れ端に掛かった**点線・中抜きのカプセル** | 時間上の1点(まだ起きていない)。記録と同じ骨格で、違いは塗り/点線の中抜きだけ。前後の出来事は出さない。過ぎて未記録なら赤の点線。残り時間は場所・人の行に並べる |
| 日のページ | 大きな日付と日記の本文 | 1日=1ページ |
| 自分の支出の詳細 | 親の支払いの**棒** → 自分の区間を**拡大した帯** | 支払いの一部を取り出したもの(時間上の点ではない) |
| 縁の詳細 | 大きな**輪郭**+名前+種類のパンくず | 時間をまたいで続くもの |
| メモ | 上に持ち主の縁、紙の本文 | 縁に綴じた文章 |
| ToDo の詳細 | 大きな**チェック欄**+題名 | やること |
| 種類・カテゴリ | 上部バー+木 | 分類の階層 |

## 4. 時間軸
| 要素 | 意味 |
| --- | --- |
| 縦の実線(灰) | 過去=起きた時間 |
| 縦の点線(灰) | 未来=まだ起きていない時間 |
| 赤い横線と赤い時刻「13:20」 | 未来と過去の境目。点は付けない(点=出来事と混ざるため)。「いま」の文字は重ねない(線と赤で伝わる) |
| 日のカード: 軸を超えて横いっぱいのすりガラスの面+「10月30日 金曜」(19px太字、本文の列に置く) | 日の区切り=1日のページ(オブジェクト)への入口。押すとその日のページ。軸はカードの後ろを通る(日が点をまとめる・軸は背景)。今日は青の細い縁+青の文字「今日」。カードは独立した面なので、中の文字は面の端から普通の余白(16)で始める(時刻列・軸の幅に合わせない) |
| 同じ横切る線+「2026年10月」 | 月の区切り(縁の時間軸) |
| 左の時刻列 | 軸の一覧(タイムライン・日のページ・縁の時間軸・これからの固定費)でのみ。点の時刻を揃えて読み比べるため。詳細の最上部(主役のカプセル)では使わない(主役に幅を使う) |
| 詳細の軸の切れ端 | 主役の上下で薄れて消える短い軸。過去=実線、未来=点線。前後の出来事・「いま」の線は置かない(主役に集中する) |
| 日の区切りは1つの部品 | タイムライン・詳細の前後・家計簿の支出一覧で同じ日のカード。家計簿は軸がないのでカードだけ。月の区切り(縁の時間軸)も同じカードで「2026年10月」 |
| 上端で薄れて消える点線+「明日以降の予定」 | 未来の続きは予定タブにある |
| 下端で薄れて消える実線 | 過去の続き(読み込み) |
| 縁の時間軸の線の色=縁の色(青緑) | その縁だけを通る糸 |

## 5. 形(1つの形=1つの意味)
| 形 | 意味 |
| --- | --- |
| **カプセル**(横長の丸) 塗り | 起きた出来事(時間上の点)。軸上の小さい節も同じ形 |
| **カプセル** 点線・中抜き | まだ起きていない出来事=予定 |
| カプセル 点線・赤の枠 | 時間が過ぎたのに記録になっていない予定 |
| **円** | 人物 |
| **ピン** | 場所 |
| **建物**(上が段の縦長) | 会社 |
| **六角** | 物 |
| **角を折った紙** | 書類 |
| 縁の形 輪郭だけ(中抜き・実線) | 未登録の縁(名前だけある) |
| **ひし形**(縁の時間軸) | 縁の事実が変わった・関係が始まった時点 |
| **チェック欄**(角丸の正方形の枠) | ToDo。塗り=完了 |
| **短い横棒**(角丸の小さい帯) | カテゴリ(お金の棒の区間と同じ形=そのカテゴリの分) |
| **横の棒** | 1つの支払いの金額。区間に分かれる。一覧の行では、割り勘・立替がある支払いだけ金額の下に小さく出す(自分の金額の文字は添えない。日の合計と詳細で読む) |
| 横の棒(月) | その月の自分の支出。区間=カテゴリ。家計簿の最上部と推移(月ごとに縦に並べる。上=新しい月)で同じ形 |
| 縁の参照=輪郭+名前(囲みなし) | そのものを指す。押すとその縁を開く。ピル(操作)・タグ(分類)と混ざらないよう囲まない |
| 棒の区間 青の塗り | 自分の分 |
| 棒の区間 灰の塗り | ほかの人の分(精算済み・立替なし) |
| 棒の区間 **斜線**(琥珀) | 立替で未精算のお金。斜線はこの意味だけ |
| └ の線 | 親 → 子(支払い → 自分の支出)。この意味だけ |
| 縦の細いガイド線+字下げ | 分類の階層(種類・カテゴリの親子) |
| 台形の拡大(棒の区間→帯) | その区間を取り出して見ている |
| 丸い錠剤形(ピル) | **操作**(絞り込み・切替。期間の切替・固定/変動などの選択も)。データには使わない。枠なしの薄い灰、選択中は薄い青+青の文字(自分が選んだ。ナビ・2列の選択と同じ) |
| 角丸の小さい四角のラベル(タグ) | データに付いた分類の名前(カテゴリ・種類) |
| ✦ | 非日常(特別な支出)。色ではなく印で示す |

## 6. 色(1つの色=1つの意味)
| 色 | 意味 |
| --- | --- |
| **文字 = 影の青**(#2B3750 / 補助 #4F5C74 / 最小 #6A768C) | 文字。自然光の影は青みを帯びる(嗜好「自然光・さりげない影」)ので、文字も影の青。黒に近い濃色(墨)は使わない(コントラストが強すぎる。2026-10-17・11-01 ユーザー) |
| **出来事の色 青灰**(#4D5F80) | 起きた出来事(記録)の塗り: 軸の節・詳細のカプセル・月のマスの印・完了したToDo。時間軸(灰青)を濃くした同じ系統=軸の上の点だから |
| **青**(#2D59B8) | **自分**: 自分の分、自分の操作(主ボタン)、自分の輪郭、今日 |
| **青緑**(#13838A) | **縁**(自分以外): 人・場所などの輪郭、縁の糸 |
| **赤**(#D3393B) | **いま・時間に遅れている**: いまの線、期限切れ、過ぎた予定 |
| **琥珀**(#B86A0E) | **貸し借り**: 立替・未精算 |
| 灰(線・補助文字) | 未来の軸・補助情報・ほかの人の分 |
| カテゴリの色 | 利用者が決めたデータの色。カテゴリの帯と棒の区間だけに使う |
| 薄い灰の面(カレンダーのマス) | 休日(日曜・祝日)。赤は「いま・遅れ」なので休日には使わない。土曜は区別しない |
| 塗りの上の文字 | 白。ダークでも塗りを白文字が読める濃さにする(黒い文字は載せない) |
| ダークテーマ = 夜の空 | 背景は黒ではなく深い紺(#121A2A。嗜好「夜景」)。同じ意味を同じ役割の色で表す。出来事の青灰(#5B6E94)・塗りの上は白文字 |
| 使わない色 | 紫(AIらしい配色)・茶色・強いグラデーション・**墨(黒に近い濃色)**(過去の指示) |

## 7. 塗りと輪郭
| 表現 | 意味 |
| --- | --- |
| 塗り | 実在・確定(起きた出来事、登録済みの縁、自分の分、完了したToDo) |
| 点線の輪郭 | まだ起きていない(予定・未来の軸) |
| 実線の輪郭だけ | 未登録・未完了(未登録の縁、未完了のToDo) |
| **塗りの光**(全ての塗りの面で同じ) | 左上の窓からの柔らかい光+上端のハイライト+その色を帯びた影。塗りの面は全てこの光を持つ(出来事のカプセル・自分の支出の帯・縁の輪郭・主ボタン)。光で種類を分けない。**種類の違いは形で示す**(出来事=カプセル、自分の支出=帯、縁=輪郭、操作=ボタン) |
| 自分の支出の帯(支払いの下にぶら下がる子、自分の支出の詳細の最上部) | 同じ「自分の支出」なので同じ見た目(青の塗りの帯)。白いカードにしない |

## 13. 言葉
- 利用者の言葉で、能動で具体的に(「支払いを保存」)。ボタンとトーストの動詞を揃える(「記録にする」→「記録にしました」)。
- 説明の文章は書かない。形で伝える(過去の指示)。
- 同じものは同じ名前(出来事の題名を見出しに、店は補足行)。


## 重複させない(11/02)
| 場所 | 出さないもの | 理由 |
| --- | --- | --- |
| 家計簿の最上部の棒 | 凡例(住居65%…) | 直下の「内訳」が同じことを色つきで言う |
| 人・場所の詳細の「この縁の時間軸」見出し | 交わった回数 | 上の数値(今年N回)と同じ |
| 作成の「金額だけで支払い」 | 「支出」という名前 | 自分の支出は支払いの一部。金額だけでも支払いを作り、自分の支出=全額。保存後は支払いを開く |

## v2から戻したもの(11/02、v2のコードと照合)
| 表現 | 意味 |

- **品目グループの入れ子**: 同じ名前+同じ値段は「×N」にまとめる。開くと、子(1個目・2個目…)が親の下に、インデント+縦の案内線+一段沈んだ面で並ぶ。支払いと自分の支出の両方で同じ見た目
- **品目の編集**: 支払いの「品目」見出しの「編集」から開くシート(品名・金額・税率・削除・追加、立替があれば 自分/半分/相手 の負担)。保存すると、支払いの合計・自分の支出・相手の分(立替)を品目から計算し直す。自分の支出の画面の「編集」も同じシートを開く

## UI v4.16(2026-11-08)— 支払い(事実)と支出(家計簿)を分ける
ユーザー指示: 支払い記録はアクティビティの記録(誰がいくら払ったか・誰が何を食べた/得たか)。支出は家計簿のエントリ(支払いのうち自分の分はいくらか・それぞれの額を何のカテゴリで計上するか)。操作は簡潔に、同じことを2度入力しない。得た分だけ負担なら支払いの「何を食べたか」をそのまま使う、奢りなら金額だけ。データ構造が明確であること。
真意: 事実(起きたこと)・取り決め(誰が負担するか)・分類(家計簿)を別々に持つ。1つの値に2つの意味を持たせない(旧 b=自分/半分/相手 は「食べた人」と「負担」を兼ねていた)。後の段は前の段を参照して計算し、計算で出せるものは保存しない。データと計算は js/money.js に1か所。

| 形・言葉 | 意味 |
|---|---|
| 支払いの「払った人」(paid: 誰・方法・金額) | 誰がいくら払ったか(事実)。既定=自分が全額。複数人も書ける |
| 品目の「使った人」(users。チップ=複数選べる操作) | その品目を食べた・使った・得た人(事実)。既定=自分。奢りでも事実は残る。使った人が違う品目は「×N」にまとめない |
| 「自分の負担」(支出の basis: 使った分 / 割り勘 / 金額を指定) | 取り決め。使った分=自分が使った品目の額÷使った人数の合計(品目の記録をそのまま使う)/ 割り勘=合計÷人数 / 金額を指定=奢り・奢られ(既定=自分が払った額)。全部自分が使って自分が払った時は聞かない |
| 支出のカテゴリ(既定)+ 品目ごとのカテゴリ(itemCat。既定と違う品目だけ) | 自分の負担額をどのカテゴリに計上するか。家計簿の集計は品目ごとに配分して数える(例: ランチの 外食1,440 と お酒800) |
| 品目の自分の額の言い方 全額 / 1/2 / 按分 / 奢り | 使った人数で割った / 割り勘・金額を比で分けた / 自分は使っていないが負担した |
| 貸し借り「花子さんに貸し ¥2,340」「健さんに借り ¥2,840」 | 自分が払った額 − 自分の負担(計算。保存しない)。保存するのは「精算済み」だけ。借りの札は補足の行(右の列は金額だけ) |
| 支出は品目を複製しない | 品目の名前・金額は支払いにだけある。直す所は1か所 |
