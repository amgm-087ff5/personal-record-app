# 個人記録 v6 「そら」 — 設計書と意味表

v6 は、v5 までのデザインシステム(意味表・トークン・形の約束)を前提にせず、白紙から設計したHTMLプロトタイプ(2026-11-11、ユーザー指示「あなたの思う最高な状態に全面的にリニューアル」「既存のデザインシステムに囚われずに」)。
v5 以前(`v3/` `v4/` `v5/`)と本番アプリ(`app/`)は変更しない。機能は v5 から1つも減らさない(棚卸し: 作業記録の inv6/A〜C)。

## 1. 考え方

このアプリは**記憶を補う**ためのもの。だから設計の軸は3つ。

1. **時間が背骨** — 記録も予定も「時間の上に置かれたもの」。時刻を表す物差しを1つだけ持つ = **空の色**(夜の紺 → 朝焼け → 昼の青 → 夕焼け → 夜)。1日の帯(0〜24時)に、起きたこと(白い面)・これから(点線)・いま(赤い針)を置く。帯を見れば、どんな1日だったかが言葉なしで分かる。
2. **承認するだけ** — 入力は推し量って埋め、利用者は確かめて直すだけ。1行書けば種類(支払い・予定・ToDo・メモ)を推し量る。支払先から前回のカテゴリを引く。過ぎた予定は「記録にする」の1タップ。
3. **思い出せる** — 全部を横断してさがせる。1年前・1か月前・先週の同じ日を出す。人や場所のページが、その縁の記憶の入口になる。

## 2. データモデル(`js/model.js` が正本)

v5 からの変更点(なぜ変えたか):

| v5 | v6 | 理由 |
|---|---|---|
| 日 = 記録の一種(`A.d1030` type:'日記'、kids を持つ) | 日 = 鍵(`days['2026-11-10']`)。日記と写真だけを持つ。記録は `date` を持つ | 日は物ではなく時間の区切り。「日記は消せない」などの特例が消える |
| 予定(PLN)と記録(A)が別の表で、`rec` で結ぶ。題・時刻・場所を二重に持つ | 同じ表 `acts`。`state: 'plan' | 'done'` が違うだけ。「記録にする」= state を変える。予定の時の時刻は `planned` に残す | 予定は「まだ起きていない同じもの」。二重入力・食い違いが起きない。予定に付けた ToDo・メモが記録にもそのまま付く |
| 予定の場所・参加者・縁(`place` `who` `ent`)と、記録の役割(`roles`)が別の形 | どちらも `roles: [{r, e | name}]` | 1つの意味に1つの形 |
| ToDo が予定と同じ表(Proxy で見え方を分ける) | `tasks` の表 | ToDo は時間の上の物ではない(期限はあるが、起きる時刻が無い) |
| 関係がエンティティの中(片側だけ。逆向きの呼び名は固定の対応表) | `rels` = 辺の表 `{a, b, role, inv | sym}` | 関係は2者の間にある。逆向きの呼び名をデータで持つ |
| 種類の項目が別の表(`TYPE_PROPS`) | 種類の中の `props` | 種類の属性は種類が持つ |
| 事実の履歴が配列の配列 | `hist: [{v, span, why}]`、`since` | 名前で読める |
| 記録の種類が自由な文字(`'食事'`) | `KINDS` の鍵(`meal`) | 絞り込み・アイコン・瞬間/期間の既定を種類が持つ |
| 支出 `X[x].pay` で支払いを指し、支払いも `x` で支出を指す | `exps[支払いのid]`(鍵が同じ) | 1対0..1 を鍵で表す。指し合いの食い違いが起きない |
| 過去の月は合計だけの別データ(`TREND`) | 全て記録から計算 | 計算で出せるものは保存しない |
| 今日は固定(2026-10-31) | 本物の今日・いま。見本データは初回の日を基準に相対で作る | いまの線が本当に動く。昨日の予定が今日は「記録待ち」になる |
| 取り消し = 関数ごとの手書きログ | `commit()` が行単位の差分を自動で取る | 全ての変更が同じ仕組みで取り消せる。後の変更を巻き戻さない |

変えていないもの: 支払い(事実: 誰がいくら払い、誰が何を使ったか)と支出(家計簿: 自分の負担の決め方 `basis` とカテゴリ)の分離(2026-11-08 のユーザー設計)。金額行(オプション・割引)。貸し借りは計算(保存するのは「精算済み」だけ)。

## 3. 情報設計

- ナビは2枚(1枚目=毎日: ホーム / アクティビティ / ＋ / ToDo / メモ。2枚目=整理: エンティティ / 家計簿 / ＋ / さがす / 設定)。＋は中央で動かない。切替はつまみ・縦ドラッグ・横スワイプ(指に近い窓から先に動く)。
- ＋ = **「入力」(入力エリア。v6.2)**。全ての種類の記録を作る場であり、作成・編集・削除の履歴を1か所で見る場。仕様の正本は INBOX.md。押すと下から全面のシートが開き、上に履歴(チャットのように。新しいものが下)、下に入力欄が固定される。急いでいる時は種類を選ばず「雑記」として置く → ルールが自動で**未確定**の記録に変換して登録 → 「確定」で実体化。長押しで音声入力。ナビの＋には未処理(雑記のまま + 未確定)の件数の印が付く。
- 詳細を開いてもナビのタブは変えない。幅900以上は左のレール、1180以上は一覧+詳細の2列。

## 4. 意味表(見た目 → 意味)。ここに無い見た目は作らない

### 4.1 色(1色 = 1意味)
| 色 | 意味 |
|---|---|
| 空のグラデ `--sky` | 時刻(0〜24時)。この意味だけ。帯・日の表示の縦の物差し・写真の枠 |
| 青 `--me` | 自分(自分の負担・今日・選択中・押せる操作) |
| 紺灰 `--done` | 起きたこと(記録) |
| 青緑 `--kin` | エンティティ(自分以外の人・場所・物) |
| 赤 `--now` | いま・遅れ・期限切れ(削除や注意には使わない) |
| 琥珀 `--owe` | 貸し借り・未精算(斜線もこの意味だけ) |
| 灰の点線 | まだ起きていない(予定)・足せる所(空の欄) |
| 青灰の点々 `--read` | 読み取った値(未確認)・自動で変換した値(未確定)。確かめる/確定すると消える |
| カテゴリの色 | 利用者のデータの色。小さい四角と棒の区間だけ |

### 4.2 形
| 形 | 意味 | なぞらえる元 |
|---|---|---|
| 空の帯(横長・角丸) | 1日 | 空の1日の移り変わり |
| 帯の上の白い面 / 点線の枠 / 赤い針 | 起きた期間 / 予定 / いま | 予定表の帯・時計の針 |
| 軸の縦の棒(節) | 期間のある記録(長さがある) | 予定表の帯 |
| 軸のひし形(節) | 瞬間(時刻だけ) | 目印 |
| 影のある白い面 | 1つの独立した物(押すと開く) | 机に置いた紙 |
| 点線の枠(影なし) | 予定(まだ起きていない)。赤の点線 = 過ぎたのに記録になっていない | 鉛筆の下書き |
| 面の中の、一段へこんだ面(入れ子) | 親の中の子(活動の中の会話・支払い) | 封筒の中の書類 |
| 右に金額のある面 + 色の四角(カテゴリ) | 支払い。右の金額 = 自分の支出 | 伝票 |
| 2色の棒(青 / 灰)+ 琥珀の斜線 | 支払いの分け方(自分 / ほかの人 / 未精算) | 帯グラフ |
| 角丸の四角の枠(塗り = 完了) | ToDo | チェック欄 |
| 右上の角を折った紙 | メモ | 付箋 |
| 頭文字の入った青緑の角丸四角 | エンティティ。点線 = 名前だけ(未登録) | 名札・印 |
| 錠剤形のピル | 操作(絞り込み・切替)。データには使わない | ボタン |
| 小さい角丸の札 | データに付いた状態(今日・遅れ・貸し・**未確定**) | 値札 |
| 右寄せの白い面(影つき)+ 中に点線の枠の入れ子 | 雑記(自分が置いた言葉)と、そこからできた未確定の記録 | 自分の発言の吹き出し |
| 面なしの小さい字の行(左寄せ) | 履歴の出来事(作った・直した・消した) | チャットの「〜が参加しました」 |
| 青の塗りの日の見出し | 今日 | 日めくりの今日 |

### 4.3 強さの順位
ホーム: いまの時刻と空の帯 > 次の予定 > 確かめる > 今日の支出 > ほか。アクティビティ: 今日の見出し(青の塗り)> いまの線 > 各日。詳細: 題 > 時刻 > 中身。家計簿: その月の自分の支出 > 棒 > 一覧。

### 4.4 言葉
説明文は置かない(形で示す)。用語: アクティビティ(記録の総称)/ 予定 / 支払い(事実)/ 支出(家計簿)/ エンティティ / メモ / ノート(エンティティごとの長い文)/ ToDo / **書く(＋の画面)/ 雑記(種類を選ばず置いた言葉)/ 未確定(自動で変換しただけの記録)/ 確定(未確定を実体にする。ボタンも「確定」)/ 置く(雑記に置く)**。ボタンとトーストの動詞を揃える。削除は「消す」、編集は「直す」。意図した例外: ホームの「固定費を除く」(大事な前提)。

### 4.5 値
全て `css/tokens.css`。文字は M PLUS 2(同梱。通信なしで表示できる)。文字の段階 40 / 28 / 19 / 15 / 13 / 12(12 未満は使わない)。押せる所は 44px 以上。余白は 4 の刻み。

## 5. v5 から足した機能
すばやく書く(1行から種類を推し量る)/ さがす(全部を横断)/ 思い出す(1年前・1か月前・先週)/ 確かめる(記録待ち・読み取ったまま・未精算を1か所で承認)/ 相手ごとの貸し借りの差し引きと一括の精算 / 日の空の帯・足あと / メモを時間の軸に置く / カテゴリを支払先から推し量る / 活動の入れ替え(中に入れる・外に出す)/ 本物の時計 / 文字の同梱(オフラインで同じ見た目)。

## 6. v6.2 で足した機能(入力エリア「入力」。詳細は INBOX.md)
雑記(種類を選ばず置く。何個でも)/ ルールベースの自動変換 → 未確定の記録(集計・一覧に含まれる。確定で実体化)/ 雑記の変換シート(雑記を見ながらその場で直す。種類も変えられる)/ LLM での一括変換(裏で実行。出力は厳格な検査を通ったものだけ。LLM は未確定の候補しか作れない)/ 作成・編集・削除の履歴(`commit()` が自動で記録。チャット風。編集は同じ対象の最新だけ)/ ＋の長押しで音声入力(離しても続き、再タップで完了 → 雑記に置く)/ ホームの「確かめる」・各詳細・家計簿での未確定の表示と確定。
